# Crater Core

Plataforma de identidad y facturación (OAuth 2.0 / OpenID Connect) y el ecosistema de productos SaaS que se integran con ella.

| Repo | Qué es |
| --- | --- |
| `accounts` | Proveedor de identidad: cuentas, organizaciones, planes y cobros |
| `crater-rs` | Crates Rust: `crater-kit` (base de servicios) y `crater-sso` (SDK para productos) |
| `crater-js` | Paquetes `@cratercore/*`: UI, SDK de React y configuración de TypeScript |
| `cli` | Comando `crater`: crear productos y levantar el entorno local |
| `handbook` | Arquitectura, convenciones y estado del ecosistema |
